📖 After you're in: how to start a test Three taps from the home page
  1. Tap a question bank on the home page.
  2. Open the folders (they open like a list — subject, then tests) and tap a test.
  3. Tap Start Test and choose how you want it:
    ⚡ Quiz Mode — for practice The right answer and explanation show as soon as you answer each question.
    ⏱️ Test Mode — like the real exam Timed. You see your score, answers and explanations at the end.

💾 Your answers save by themselves. Close it any time — it waits for you under Continue where you left off on the home page.

💡 Having trouble? The usual problems and what to do
Asked for the code again after a week That's normal: each browser asks once a week. Type the same code again (scroll up in your chat with the bot) — it works for 30 days. Please don't ask the bot for a new one: every new code signs out your other devices.
“That code isn't right” Copy it from the bot instead of typing it (tap the code once), or tap the bot's Open the website button. Only the newest code works.
“Already signed in on two other devices” One code works on two devices. Send /code to the bot for a new one — that signs the old devices out.
It asks for the code every time I open it Telegram may open the site inside its own browser, which forgets you. Use your phone's own browser: open qb.neetpgbot.in in Safari (iPhone) or Chrome (Android) and sign in there. To get an icon: Chrome → ⋮ → Add to Home screen. On iPhone, Safari → Share → Add to Home Screen, then open the new icon and sign in inside it (on iPhone the icon counts as its own device). Each browser counts as one of your two devices.
“Your access has ended” or the code expired Codes last 30 days — send /code to the bot for a new one. If the bot says you're not in the group, contact the owner below.
